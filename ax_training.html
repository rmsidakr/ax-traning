AX 개요

정보보호센터는 AX를 2 Track으로 추진합니다. 오늘 교육은 그중 Track 1의 3단계입니다.

Track 1 — AI Native 정보보호센터Track 2 — 그룹별 전문가 양성(FDE)
대상전체 센터원그룹별 대표과제와 대표자
하는 일① 사용환경 준비(개인 PC) → ② AI 실무교육 입과 → ③ 업무 적용 실습컨설팅·과제 확정 → 설계 → Task Agent 적용 → E2E workflow 운영
기간10월~11월대표과제 Full Cycle 3개월 × 2턴
도구Claude Code · 사내 Model/MCP/Agent Gateway동일 (구현은 Claude Code)

환경 준비와 온라인 교육을 지나, 이제 본인 PC로 내 업무에 직접 적용해 보는 자리입니다.

왜 "교육"이 아니라 "실습"인가

교육 아닌 과제로 배운다듣는 것으로는 늘지 않습니다
외부 전문가는 설계만 돕는다과제를 끌고 가는 사람은 우리입니다
구현은 Claude Code로 직접설계한 사람이 직접 지시하고 검증합니다

Jupyter 노트북 열기와 설치 확인 (0·1단계)

  1. VS Code에서 파일 → 파일 열기로 배포받은 pc_setup.ipynb를 엽니다.
  2. "이 창에서 신뢰할 수 없는 파일을 허용하시겠습니까?" 창이 뜨면 열기를 누릅니다. "제한 모드에서 열기"를 누르면 ▶ 버튼이 나오지 않습니다.

Skill(Claude Code에 넣어 두는 업무 설명서)을 설치하고, 메일로 받은 Virtual Key(사내 AI를 쓰는 열쇠)를 키 파일에 넣습니다. 설치와 키 자리 만들기는 노트북이 하고, 키는 내가 직접 넣습니다.

  1. 메일로 받은 Skill 압축 파일(ai-gateway-skills…zip)을 다운로드 폴더에 그대로 저장합니다. 압축은 직접 풀지 않습니다.
  2. Jupyter 노트북 6단계의 ▶를 누릅니다. 아직 키가 없어서 ❌가 나오는 것이 정상입니다.
    # 첫 ▶ 결과 (설치 과정 줄은 생략) ✅ Skill 설치됨: C:\Users\…\.claude\skills\litellm-gateway 👉 아래 파란 경로를 Ctrl + 클릭해 키 파일을 열고, LITELLM_API_KEY= 바로 뒤에 Virtual Key를 붙여 넣고 Ctrl + S C:\Users\…\.claude\litellm-gateway.env ❌ 아직 Virtual Key가 비어 있습니다. 👉 키를 넣고 저장한 뒤 이 칸의 ▶를 다시 누르세요.
  3. 결과에 나온 파란 경로를 Ctrl + 클릭해 키 파일을 엽니다. "신뢰할 수 없는 파일을 허용하시겠습니까?" 창이 뜨면 열기를 누릅니다.
  4. 메일로 받은 Virtual Key를 LITELLM_API_KEY= 바로 뒤에 붙여 넣고 Ctrl + S로 저장합니다.
    # 본인 LiteLLM virtual key 를 넣으세요 (이 파일은 절대 커밋하지 않습니다) LITELLM_API_KEY=sk-●●●●●●●●●●●●●●●●●●●●●● LITELLM_BASE_URL=https://gateway.security.samsungds.net

    키 파일에 키를 붙여 넣은 모습. 실제 키는 가려서 표시했습니다.

  5. 6단계의 ▶를 다시 누릅니다.
    # 이렇게 나오면 성공 (6단계) ✅ Skill 설치됨: C:\Users\…\.claude\skills\litellm-gateway ✅ Virtual Key 입력됨 (●●●● N자) / Gateway 주소: https://gateway.security.samsungds.net 👉 Claude Code 화면에 /exit 를 입력해 끄고, claude 를 입력해 다시 켜세요. 새 Skill은 다시 켜야 적용됩니다.
  6. 위 👉 안내대로 Claude Code를 다시 켭니다(/exit → claude). 새 Skill과 5단계 설정은 다시 켜야 적용됩니다.
  7. 사용할 수 있는 Skill 목록 알려줘를 입력해 litellm-gateway가 보이면 성공입니다.
🔒 안전 규칙 3: 키는 키 파일에만

키는 VS Code 편집기에서 키 파일에만 넣고, 다른 사람과 공유하지 않습니다. Claude Code 대화창에는 붙여 넣지 않고, Claude Code가 키 파일을 다루겠다고 물으면 No를 고릅니다.

더 알아보기: 키 파일과 Skill 폴더 (눌러서 펼치기)

키 파일은 내 홈 폴더의 .claude\litellm-gateway.env입니다. Claude Code 대화창에 붙여 넣은 내용은 AI 모델로 전달되고 PC 기록에도 남기 때문에, 키는 이 파일에만 넣습니다.

Claude Code는 5단계 설정 때문에 이 키 파일을 읽거나 고치지 못합니다. !로 시작하는 명령을 입력하라고 안내해도 따라 하지 않습니다.

설치가 끝난 뒤 .claude\ai-gateway-skills 폴더는 지우거나 옮기지 않습니다. Skill이 이 폴더를 가리키고 있어서, 없어지면 Skill이 작동하지 않습니다.

압축 파일 이름은 묶음 이름 ai-gateway-skills이고, 그 안에 들어 있는 Skill 이름이 litellm-gateway입니다.

Gateway 조회

💡 노하우·힌트
  • 도구 이름은 몰라도 됩니다. 내 업무와 알고 싶은 것을 말하면 Skill이 찾아 줍니다.
  • 범위를 정하고 "시스템마다 한 번씩만": 기간·대상을 정해 말하고, 같은 조회를 되풀이하지 않게 합니다. 분석에 쓸 건별 데이터는 가져오되 "화면에는 건수와 요약 표만" 보여 달라고 하면 덜 기다립니다. 사람을 알아볼 수 있는 정보(이름, 사번, 연락처)는 빼 달라고 합니다.

1-B. ② 연계·분석: 많은 데이터에서 필요한 것 찾기

AI 분석

과제: 조회한 많은 데이터를 엮어 내 업무에 필요한 것을 분석합니다. 사람이 하나씩 보기 어려운 양을 한 번에 엮어 보는 일은 Gateway가 아니라 AI가 원래 잘하는 일입니다.

💡 노하우·힌트
  • 필요한 것을 분명히: 무엇을 기준으로 엮고 무엇을 찾을지 말하면, 많은 데이터에서도 필요한 것만 골라 분석해 줍니다.
  • "새로 조회하지 말고 위 데이터만": 이미 가져온 데이터로 분석만 하게 해서 빠르고 정확합니다.
  • "짐작은 짐작이라고": 사실과 추정을 나눠 받으면 보고에 그대로 쓰기 쉽습니다.
  • 계산하려고 코드를 실행하겠다는 확인창이 뜨면 3. No를 누르고 "계산은 답에서 바로 해줘"라고 입력합니다.

💡 이런 도구가 되려면: 데이터가 AI Ready여야 합니다

화면의 판단은 AI가 하지만, 판단의 재료는 데이터입니다. 접수 요청·정책문서·KM 결정 이력·차단 이력이 AI가 찾고 읽을 수 있는 형태(조항 번호, 결정 결과와 날짜 같은 항목, 서로 이어지는 번호)로 준비돼 있어야 버튼 하나로 됩니다.

1교시 조회가 쉬웠던 것도 Gateway에 데이터가 이미 연결돼 있었기 때문입니다. 준비가 덜 된 데이터(화면의 △·✗)는 AI가 짐작하게 되고, 그만큼 사람이 확인해야 합니다.

2교시는 1교시 대화를 이어서 합니다. Claude Code가 꺼졌으면 실습 폴더에서 claude -c로 켭니다. 대화가 없으면 흐름 파일만으로도 시작할 수 있습니다.

2-A. 만들기: 내 흐름을 [실행] 버튼으로

도구 만들기

과제: 1교시 대화에 이어서 "방금 한 흐름과 prompts\내 업무 흐름.md로, [실행] 버튼 하나로 도는 도구를 만들어줘"라고 합니다. 처음에는 [실행] 버튼과 미리보기만 만듭니다. 계획을 먼저 본 뒤 만들고 켜 달라고 합니다.

💡 노하우·힌트
  • 계획부터: "만들기 전에 계획부터 보여줘"로 시작합니다. [실행]이 내 흐름의 ①②를 하는지 보고 만들고 켜 달라고 합니다. 주소만 받고, 버튼은 내가 눌러 봅니다.
  • 지킬 것은 처음에 한 번에: 내 PC에서만 열리게, 설치 없이 지금 PC에 있는 것만으로, 키는 도구가 실행될 때 키 파일에서 읽게(키 파일은 열어 보지 말고, 키 값은 화면·터미널·오류에 찍지 않게), 분석은 강사가 알려 준 사내 AI 모델로(다른 모델로 바꾸지 않게), 화면과 보낼 내용에 이름·사번·연락처는 빼게. 나중에 말하면 잘 지켜지지 않습니다.
  • 분석은 AI에게: [실행]할 때마다 조회 결과와 흐름 파일을 사내 AI에 넘겨 분석하게 합니다. 그러면 나중에 흐름 파일만 고쳐도 분석과 형식이 바뀝니다.

2-B. 눌러 보기: 미리보기를 보고 말로 고치기

실행·고치기

과제: 답에 나온 주소를 Ctrl + 클릭해 열고 [실행]을 누릅니다. 미리보기를 1-C에서 받은 메일·메신저와 견주어 보고, 마음에 안 드는 곳을 말로 고칩니다.

💡 노하우·힌트
  • 오류는 그대로 붙여 넣기: 화면이나 터미널의 오류 글자를 복사해 "이 오류 고쳐줘"라고 합니다. 조회가 여러 개면 하나만 먼저 되게 하고 나머지를 붙입니다.
  • 근거 하나는 대조: 미리보기에서 찾은 것 하나의 근거를 1교시에 받은 결과에서 찾아봅니다. 값은 조회할 때마다 조금 바뀔 수 있습니다.
  • 분석·형식은 흐름 파일에서: "내 업무 흐름.md의 ②를 ○○ 기준으로 고쳐줘"라고 한 뒤 다시 [실행]. 화면 모양은 말로 고칩니다(예: "요약을 맨 위에"). 이름·사번·연락처가 보이면 흐름 파일 ②에 빼라고 적습니다.

2-C. 나에게 보내기: [나에게 보내기] 붙이기

메일·메신저 발송

과제: 미리보기 아래에 [나에게 보내기]를 붙여, 흐름 파일 ③의 받는 곳(메일·메신저)으로 나에게 보냅니다. 받는 사람은 나로 고정하고, 방금 본 미리보기를 그대로 보내게, 미리보기를 본 뒤에만 누를 수 있게, 누르면 한 번 더 확인하게, 보낸 뒤에는 버튼이 잠기게 합니다. 첫 발송은 내가 버튼으로 하고, 받은 것을 확인합니다.

💡 노하우·힌트
  • 내 정보는 직접 입력해 고정: 요청 끝에 내 정보(Knox ID, 메일이면 메일 주소도)를 적습니다. 비워 두면 PC에 있는 다른 주소가 들어갈 수 있습니다.
  • 보내기는 시험하지 않게: "보내기는 시험하지 말고 버튼만 붙여줘. 첫 발송은 내가 할게."
  • 확인 창에 내 Knox ID(메일이면 주소)가 글자 그대로 보이는지 보고 누릅니다. 오류가 나도 다시 누르기 전에 메일함·메신저부터 확인합니다.

2-D. 내 도구로 남기기: 더블클릭으로 다시 열기

내 도구

과제: (된 사람부터) 켜 둔 도구를 끄고, 더블클릭하면 도구가 켜지고 브라우저가 열리는 파일을 실습 폴더에 만들어 달라고 합니다. 그 파일로 다시 열어 [실행]까지 해 봅니다.

💡 노하우·힌트
  • 먼저 "켜 둔 도구를 꺼줘": 같은 도구가 두 번 켜지면 열리지 않습니다.
  • 파일 이름은 업무 이름으로(예: "보안정책 개선 검토 도우미"). 흐름이 바뀌면 내 업무 흐름.md부터 고치고 "이 파일대로 도구도 맞춰줘"라고 합니다.
  • 오늘 키는 공용이라 오후 그룹별 실습이 끝나면 지웁니다. 도구는 실습 폴더에 남고, 개인 Virtual Key를 받으면 다시 씁니다.
⚙️ 소개: 모델과 Effort 고르기 (오늘은 기본값 그대로, 눌러서 펼치기)

Claude Code는 모델과 Effort(생각의 깊이)를 바꿀 수 있습니다. 작업 성격에 맞추면 더 빠르거나 더 정확해집니다.

설정입력고를 수 있는 값
모델/modelhaiku · sonnet · opus
Effort/effortlow · medium · high · xhigh · max
  • 사내 배포 기본값은 opus + medium입니다. 오늘 실습은 기본값 그대로 두면 됩니다.
  • 조회·요약처럼 단순한 일은 낮게, 설계·코드처럼 여러 단계를 거치는 일은 높게 쓰면 좋습니다.
  • 터미널에서 시작할 때 미리 지정할 수도 있습니다: claude --model sonnet --effort high

🔒 Effort를 올리면 느려지고 공용 Virtual Key의 자원을 더 많이 씁니다. 조회만 할 때는 올리지 않습니다. 오늘은 기본값으로 진행하고, 돌아가서 큰 작업을 할 때 떠올리세요.

4. 마무리

오늘 가져가는 것
  • 업무 말로 사내 데이터를 조회하고, AI로 엮어 분석해, 나에게 받는 흐름
  • 초안 → 확인 → 실행의 안전한 AI 활용 습관
  • 실습 폴더의 prompts에 저장한 내 업무 흐름 (교육이 끝나도 남습니다)
  • 버튼 하나로 도는 내 업무 도구 (실습 폴더에 남습니다)

실습 환경 정리 (노트북 10단계) 오후 그룹별 실습이 끝난 뒤

오늘 쓴 Virtual Key는 공용 키입니다. 오후 그룹별 실습까지 끝나면 PC에 남기지 않고 지웁니다. 노트북 10단계가 해 줍니다.

  1. 노트북을 열고 0단계 ▶를 먼저 누릅니다. (오전과 같은 순서)
  2. 10단계의 ▶를 누릅니다 → 지울 목록만 보여 줍니다. (아직 지우지 않습니다)
  3. 목록을 확인하고 ▶를 한 번 더 누릅니다 → 실제로 지웁니다.
# 이렇게 나오면 성공 (10단계, 두 번째 ▶) 🧹 지움 - Skill 링크 🧹 지움 - Skill 압축을 푼 폴더 🧹 지움 - Virtual Key 파일 ✅ 오늘 설치한 Skill과 Virtual Key를 지웠습니다. 실습 폴더와 저장한 프롬프트는 그대로 남아 있습니다. 다시 쓰려면 개인 Virtual Key를 받아 6단계를 다시 하면 됩니다.
