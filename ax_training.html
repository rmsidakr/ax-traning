🔒 안전 규칙 3: 키는 .env에만

Claude Code 대화창에 붙여 넣은 내용은 AI 모델로 전달되고 PC 기록에도 남습니다. 키는 VS Code 편집기에서 .env 파일에만 넣고, 실습 폴더는 다른 사람과 공유하지 않습니다.

Claude Code는 8단계 설정 때문에 .env를 읽지 못합니다. 그래도 .env를 열어 보거나 출력하겠다고 물으면 No를 고릅니다.

언제든 쓰는 로컬 웹앱 시연 강사 시연

보여 줄 것: 저장한 프롬프트를 한 단계 더 발전시켜, 브라우저에서 버튼 하나로 일일 브리핑을 만드는 웹앱입니다. "오늘 배운 것을 이렇게까지 키울 수 있다"는 목표를 보여 줍니다.

완성 화면 구성

http://localhost · 일일 보안 브리핑 (예시 화면)
기간어제 ▾담당 영역예) VPN
브리핑 만들기
결과 미리보기: 제목 / 3줄 요약 / 상위 5개 표 / 권고 조치
나에게 메일 보내기→ 한 번 더 확인 창

시연 순서 (5분)

  1. 결과 먼저 (2분): 웹앱을 열고 [브리핑 만들기] → 미리보기 → [나에게 메일 보내기] → 확인 창 → 메일함 확인
  2. 만든 과정 (2분): 아래 프롬프트 다섯 개만으로 만들었다는 것을 보여 주며 노하우를 설명
  3. 마무리 (1분): "저장한 프롬프트가 웹앱의 출발점"이라는 메시지
강사 사전 제작: Claude Code에게 시킨 프롬프트 순서 (눌러서 펼치기)

교육 전에 강사가 사내망 PC의 실습 폴더에서 차례로 실행해 만듭니다. Claude Code는 셋팅 때의 설정으로 .env를 읽지 못하므로, 변수 이름을 프롬프트에 적어 줍니다. 웹앱이 Gateway의 Splunk·메일 MCP를 부르는 방식: [확인 필요: 웹앱에서 Gateway MCP 호출 방법]
