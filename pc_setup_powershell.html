PC 환경 셋팅 — 노트북이 안 될 때 PowerShell로 직접 하기

Jupyter 노트북(pc_setup.ipynb)이 열리지 않거나 ▶가 동작하지 않을 때만 씁니다. 노트북과 같은 일을 PowerShell 명령으로 합니다. 단계 번호는 노트북과 같습니다.

시작 전에
① PowerShell 열기: 시작 버튼(작업 표시줄 가운데 윈도 로고)을 마우스 오른쪽 클릭 → 터미널. 관리자로 열지 않습니다.
② 명령은 한 줄씩 복사 → PowerShell 창에 Ctrl + V(또는 마우스 오른쪽 클릭) → Enter. 줄을 이어 붙이지 않습니다.
③ 빨간 글씨가 나오거나 '이렇게 나오면 성공'과 다르면, 화면을 그대로 두고 손을 듭니다.
④ Virtual Key는 6단계의 사내 키 입력 명령에만 씁니다. Claude Code 대화창에는 붙여 넣지 않습니다.
단계 할 일 입력할 명령 (한 줄씩) 이렇게 나오면 성공 안 될 때
1 Python 3.12 확인 py -3.12 --version Python 3.12.x → 2단계로 다른 글자나 빨간 글씨 → 1-1부터
1-1 설치파일 받기 (1분 안팎) $ProgressPreference='SilentlyContinue'; Invoke-WebRequest https://www.python.org/ftp/python/3.12.10/python-3.12.10-amd64.exe -OutFile $env:TEMP\python-3.12.10-amd64.exe -UseBasicParsing 아무것도 나오지 않고 다음 줄이 뜸 빨간 글씨 → 손
1-2 받은 파일이 맞는지 확인 (Get-FileHash $env:TEMP\python-3.12.10-amd64.exe).Hash -eq '67B5635E80EA51072B87941312D00EC8927C4DB9BA18938F7AD2D27B328B95FB' True False → 1-1 다시. 그래도 False면 손
1-3 설치 (이 사용자에게만, 1~2분) Start-Process $env:TEMP\python-3.12.10-amd64.exe -ArgumentList '/passive','InstallAllUsers=0','PrependPath=1','Include_launcher=1','InstallLauncherAllUsers=0','Include_test=0' -Wait 설치 창이 떴다가 저절로 닫히고 다음 줄이 뜸 설치 창에 오류 → 손
1-4 PowerShell 창을 닫고 새로 연 뒤 다시 확인 py -3.12 --version Python 3.12.10 손
2 Claude Code 확인 claude --version 2.x.x (Claude Code) "인식되지 않습니다" → 손 (사전 배포 누락)
3 사내 AI 연결 확인 건너뜁니다. 5단계에서 Claude Code가 대답하면 정상입니다.
4 Node.js 확인 node --version v로 시작하는 버전 (예: v24.22.1) → 5단계로 "인식되지 않습니다" → 4-1부터
4-1 설치파일 받기 (1분 안팎) $ProgressPreference='SilentlyContinue'; Invoke-WebRequest https://nodejs.org/dist/v24.22.1/node-v24.22.1-x64.msi -OutFile $env:TEMP\node-v24.22.1-x64.msi -UseBasicParsing 아무것도 나오지 않고 다음 줄이 뜸 빨간 글씨 → 손
4-2 받은 파일이 맞는지 확인 (Get-FileHash $env:TEMP\node-v24.22.1-x64.msi).Hash -eq '3BDA4BAF1EE709B33CF920DD633106DDB23951E322BFF9C03EC9F64AB8981B01' True False → 4-1 다시. 그래도 False면 손
4-3 설치 (1~2분) Start-Process msiexec -ArgumentList '/i',"$env:TEMP\node-v24.22.1-x64.msi",'/passive','/norestart' -Wait 관리자 승인 창 → 예. 설치 창이 저절로 닫힘 승인 창에서 '아니요'를 눌렀으면 4-3 다시
4-4 PowerShell 창을 닫고 새로 연 뒤 다시 확인 node --version v24.22.1 손
5 실습 폴더 만들고 들어가기 cd ~
mkdir ax-training -Force | Out-Null; cd ax-training		 줄 앞이 …\ax-training>로 바뀜 손
5-1 키 보호 설정 만들기 (Claude Code가 키 파일을 읽지 못하게) mkdir .claude -Force | Out-Null; if (Test-Path .claude\settings.json) { '설정 파일이 이미 있습니다. 다음 줄로 확인하세요.' } else { [IO.File]::WriteAllText("$HOME\ax-training\.claude\settings.json", '{"permissions":{"deny":["Read(~/.claude/litellm-gateway.env)","Read(./.env)","Read(./.env.*)"]}}'); '보호 설정을 만들었습니다.' } 보호 설정을 만들었습니다. (또는 '이미 있습니다') 빨간 글씨 → 손
5-2 보호 설정 확인 Select-String -Path .claude\settings.json -Pattern 'litellm-gateway.env' -Quiet True False → 손
5-3 Claude Code 첫 실행 claude
· 처음 화면(테마, 영어 안내 2개)은 Enter
· "이 폴더를 믿을지" 화면은 ↓ 키로 Yes, I trust this folder → Enter (그냥 Enter면 꺼짐)
· 입력: 안녕! 너는 무엇을 도와줄 수 있어?		 한국어로 대답이 옴 꺼지면 claude 다시 → Yes. 대답이 없으면 손
6 새 PowerShell 창 열기 5-3의 창은 Claude Code가 켜져 있으므로 그대로 두고, 시작 버튼 오른쪽 클릭 → 터미널로 창을 하나 더 엽니다. 6-2~6-6은 이 새 창에 입력합니다. Claude Code 입력창에는 넣지 않습니다.
6-1 Skill 압축 풀기 (파일 탐색기에서) 다운로드 폴더의 ai-gateway-skills…zip 오른쪽 클릭 → 모두 압축 풀기 → 압축 풀기 같은 이름의 폴더가 생김 손
6-2 풀린 폴더로 이동 ① 풀린 폴더를 열어 install.ps1이 보이는 폴더까지 들어감 (한 겹 더 들어가야 할 수 있음)
② 뒤로(←) 한 번 나와서, 그 폴더를 오른쪽 클릭 → 경로로 복사
③ 새 PowerShell 창에 cd (cd와 띄어쓰기)를 치고 Ctrl + V → Enter
④ 확인: Test-Path .\install.ps1		 ④에서 True False → ①부터 다시. 폴더를 한 겹 더 들어가 봄
6-3 Skill 설치 【사내 Skill 설치 명령】 【사내 명령의 성공 화면】 손
6-4 Virtual Key 입력 【사내 키 입력 명령】 【사내 명령의 성공 화면】 손
6-5 Skill 확인 Test-Path $HOME\.claude\skills\litellm-gateway\SKILL.md True False → 6-3 다시. 그래도 False면 손
6-6 키가 들어갔는지 확인 (키 값은 화면에 나오지 않음) Select-String -Path $HOME\.claude\litellm-gateway.env -Pattern '^LITELLM_API_KEY=\S' -Quiet True False → 6-4 다시. 그래도 False면 손
6-7 Claude Code 다시 켜기 (새 Skill 적용) 5-3의 Claude Code 창에서: /exit → claude
· 입력: 사용할 수 있는 Skill 목록 알려줘		 목록에 litellm-gateway가 보임 손
⚠ 6-1에서 풀린 폴더는 교육이 끝날 때까지 지우거나 옮기지 않습니다. Skill이 이 폴더를 가리키고 있어서, 없어지면 Skill이 작동하지 않습니다.
9 최종 점검 (6단계의 새 창에서) py -3.12 --version; claude --version; node --version; Test-Path $HOME\ax-training\.claude\settings.json; Test-Path $HOME\.claude\skills\litellm-gateway\SKILL.md; Select-String -Path $HOME\.claude\litellm-gateway.env -Pattern '^LITELLM_API_KEY=\S' -Quiet 버전 3줄 + True 3줄 빨간 글씨나 False가 있는 줄의 단계로 돌아감

교육이 끝난 뒤: 실습 환경 정리 (노트북 10단계와 같음)

강사가 안내할 때 합니다. Claude Code와 VS Code를 모두 닫고, PowerShell 창을 새로 열어 입력합니다. 실습 폴더와 만든 파일은 그대로 남습니다.

단계 할 일 입력할 명령 (한 줄씩) 이렇게 나오면 성공
10-1 지울 폴더 위치 보기 (먼저!) (Get-Item $HOME\.claude\skills\litellm-gateway -Force -ErrorAction SilentlyContinue).Target …\skills\litellm-gateway로 끝나는 경로 한 줄. 이 경로에서 \skills\litellm-gateway 앞까지가 6-1에서 푼 폴더입니다(메모해 둠). 아무것도 안 나오면 그대로 다음 줄로
10-2 Skill 지우기 $s = "$HOME\.claude\skills\litellm-gateway"; if (Test-Path $s) { if ((Get-Item $s -Force).LinkType) { cmd /c rmdir "$s" } else { Remove-Item $s -Recurse -Force } } 아무것도 나오지 않음
10-3 6-1에서 푼 폴더 지우기 (파일 탐색기에서) 10-1에서 메모한 폴더를 탐색기에서 찾아 그 폴더만 삭제합니다. 다운로드 폴더 자체나 zip 파일은 지우지 않습니다. 헷갈리면 손 폴더가 휴지통으로 감
10-4 Virtual Key 파일 지우기 Remove-Item $HOME\.claude\litellm-gateway.env, $HOMEx-training\.env -Force -ErrorAction SilentlyContinue 아무것도 나오지 않음
10-5 지워졌는지 확인 Test-Path $HOME\.claude\skills\litellm-gateway; Test-Path $HOME\.claude\litellm-gateway.env False 2줄 (True가 있으면 손)

다운로드 폴더의 Skill 압축 파일은 지우지 않습니다. 개인 Virtual Key를 받으면 6단계를 다시 할 때 씁니다.
