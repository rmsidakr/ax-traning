# 리허설 순서 (강사용, 사내망 Windows 교육생 PC에서)

> `REVIEW_LOG.md` 남은 일 3·4를 실제로 돌리는 순서대로 모은 표입니다. 무엇을 재고 기준이 무엇인지는 각 강사 자료의 8절에 있고, 여기서는 **순서와 결과에 따라 고칠 곳**만 적습니다.
> 교안이 바뀔 수 있는 항목(★)부터 결과를 보고, 운영 항목은 대본·대응표만 고칩니다.

## 0. 준비물

- [ ] Windows 11 교육생과 같은 조건의 PC 1대(셋팅 노트북을 처음부터 돌릴 수 있게 Python 3.12·Node.js·Skill이 없는 상태면 가장 좋음), 동시 실행용 PC 2대 더(강사·보조강사)
- [ ] 메일로 받은 Skill 압축 파일(`ai-gateway-skills*.zip`)을 다운로드 폴더에, 실습용 Virtual Key
- [ ] 시계(초 단위), 캡처 도구, 기록표(1교시 8절·2교시 8절 끝의 기록표)
- [ ] 1교시 2절 '전날' 항목(시연 PC 메일 주소, 확인창 미리 허용 없음)

## 1. 셋팅 노트북 (0 → 9단계)

| 순서 | 할 것 | 결과에 따라 고칠 곳 |
|---|---|---|
| 1단계 | Python 3.12 실제 설치(공식 사이트 다운로드), ipykernel 설치 | 막히면 교안 '막혔을 때' 표, `installers/README.md`의 ipykernel 묶음 안내 |
| ★ 3단계 | **어느 방식으로 ✅가 되는지**(사내 AI Gateway / Bedrock / ⚠️) 화면 그대로 캡처 | 교안 셋팅 3단계 안내 상자("3단계는 ⚠️나 Bedrock이 나와도 넘어갑니다") |
| 6단계 | 실행 전에 `python tools/test_step6.py <zip 경로>`(가짜 홈 폴더에서 6가지 경우). 그다음 노트북 6단계 실제 실행 → `icacls`가 그룹 정책에 막히는지 → Claude Code에서 `사용할 수 있는 Skill 목록 알려줘`로 Junction Skill이 보이는지 | 막히면 `tools/pc_setup_core.py` 6단계, 교안 6단계·'막혔을 때' 표 |
| 7·8단계 | Splunk·일정 조회가 Claude Code 화면에 나오는지 | 교안 연결 테스트 |
| 9단계 | 최종 점검표가 0~6단계 결과와 맞는지 | — |

**노트북 대신 PowerShell 표(`pc_setup_powershell.html`, 메일 본문)로 1회** — 노트북을 쓰지 않은 Windows 11 PC(또는 가짜로 노트북이 안 되는 상황)에서 표 1 → 9단계를 글자 그대로 붙여 넣어 봅니다. **먼저 6-3·6-4 노란 칸에 사내 명령과 성공 화면을 넣습니다(키는 넣지 않음).** 끝나고 10-1~10-5. 볼 것: Windows 11 터미널(시작 버튼 오른쪽 클릭 → 터미널)에서 붙여 넣기가 되는지, 6-2 '경로로 복사' → `cd ` 붙여넣기가 되는지, 6-5·6-6이 True인지, **사내 키 입력 명령을 친 뒤 `%APPDATA%\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt`에 키가 남는지**(남으면 대응을 정함), 10-1이 풀린 폴더 경로를 보여 주는지

## 4. 동시 실행 (PC 3대)

- 같은 1교시 ① 문장과 2교시 [실행]을 3대에서 동시에 돌려 1대일 때와 시간을 비교합니다. 20명 규모는 Gateway 운영 쪽 답(동시 사용 한도·공용 키 한도)과 함께 봅니다.
