# 4. 마무리 강사 진행 자료 (강사·보조강사용)

> 강사용 문서입니다. 교안에는 넣지 않습니다. 교안 4. 마무리에는 오늘 가져가는 것, 실습 환경 정리(노트북 10단계), 돌아가서 계속 쓰려면, 업무 재정의(왜 다시 정의하나 + 접근 방식 ①②③)만 있습니다.
> 마무리는 **하루 끝 16:30–17:00(30분)**, 오후 그룹별 실습이 끝난 뒤 **오전 강사가 전체 대상으로** 진행합니다(2026-10-28 사용자 결정). 오전 끝은 2교시 '끝(3분)'으로 점심에 들어갑니다.
> 시각은 계획입니다(미측정).

## 1. 진행 순서

| 시각 | 단계 | 보여 줄 것·할 것 | 말할 것 |
|---|---|---|---|
| 16:30 | 모이기 (2분) | 교안 4. 마무리 첫 화면, '오늘 가져가는 것' | 오늘 한 흐름(조회 → 분석 → 받기)과 남는 것 두 가지(흐름 파일, 내 도구) |
| 16:32 | 실습 환경 정리 (8분) | 교안 '실습 환경 정리'. 다 같이 노트북 0단계 ▶ → 10단계 ▶(목록만) → 확인 → 10단계 ▶ 한 번 더 | 2절 |
| 16:40 | 돌아가서 계속 쓰려면 (2분) | 교안 '돌아가서 계속 쓰려면' | 2절 |
| 16:42 | 업무 재정의 (18분) | 교안 '업무 재정의'(왜 다시 정의하나 + 접근 방식 ①②③) | 3절. 강사가 화두를 던지고 자유 토론 |
| 17:00 | 끝 | | |

## 2. 실습 환경 정리·계속 쓰기에서 말로 전할 것

- **0단계를 먼저**: 오후에는 노트북 커널이 새로 떠 있을 수 있어, 10단계만 누르면 오류가 납니다.
- **두 번 누르기**: 첫 ▶는 지울 목록만 보여 줍니다. 목록을 보고 한 번 더 눌러야 지워집니다.
- 보조강사는 ✅ "오늘 설치한 Skill과 Virtual Key를 지웠습니다."가 나왔는지 돌며 확인합니다. 정리가 끝나야 업무 재정의로 넘어갑니다.
- **Skill 압축 파일(다운로드 폴더)은 지우지 않게 합니다.** 개인 Virtual Key를 받은 뒤 6단계가 그 파일을 다시 찾습니다.
- 개인 Virtual Key는 "준비되는 대로 따로 안내"까지만 말합니다. 오늘 쓴 실습용 키가 실습 종료 후 키 관리자에 의해 만료 처리된다는 것은 교육생에게 알리지 않습니다.

## 3. 업무 재정의 (Open discussion)

- 교안에는 **필요성(왜 다시 정의하나)과 접근 방식(① 쪼개기 ② 나누기 ③ 다시 짜기)까지만** 있습니다.
- **화두는 강사가 직접 던집니다.** 교안에 질문이나 토론 순서는 두지 않습니다.
- 토론은 자유 양식입니다.
